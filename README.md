# Check-It

Sistema de monitoreo IoT multi-sensor, con backend en Python y microcontrolador ESP32.

# Qué hace
Recolecta lecturas de múltiples sensores conectados a un ESP32, las almacena en una base de datos MySQL y las muestra en una interfaz de escritorio construida con PySide6.

# Tecnologías
- Python
- PySide6 (interfaz de escritorio)
- MySQL
- MariaDB
- ESP32 (microcontrolador) junto a sensores comunes
- Arduino
